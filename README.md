# Court Judgments (India) — Android app

Search Supreme Court and High Court judgments by party name, case number or subject,
and open / download the judgment PDF.

Data: public open datasets (CC-BY-4.0) —
[Indian Supreme Court Judgments](https://registry.opendata.aws/indian-supreme-court-judgments/) and
[Indian High Court Judgments](https://registry.opendata.aws/indian-high-court-judgments/)
by Pradeep Vanga / Dattam Labs. This app is an independent viewer; it is not an official court app.
